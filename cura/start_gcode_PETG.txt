; Ender 3 V2 - Professional Firmware + probe (UBL) - PETG start G-code
M140 S{material_bed_temperature_layer_0} ; Start heating bed
M104 S150 ; Nozzle to 150C: warm but no PETG ooze onto the bed while probing
M190 S{material_bed_temperature_layer_0} ; Wait for bed (probe the bed at print temperature)
G28 ; Home all axes
G29 P1 ; Probe and build the mesh
G29 A ; Activate UBL
C108 ; Close the mesh viewer
M117 Heating nozzle ; Shows on the LCD's status line, the firmware may replace it at once
M109 S{material_print_temperature_layer_0} ; Heat nozzle to print temperature and wait
G92 E0 ; Reset extruder
G1 Z2.0 F3000 ; Lift nozzle
G1 X0.1 Y20 Z0.3 F5000.0 ; Move to prime line start
G1 X0.1 Y200.0 Z0.3 F1500.0 E15 ; Prime line 1
G1 X0.4 Y200.0 Z0.3 F5000.0 ; Step over
G1 X0.4 Y20 Z0.3 F1500.0 E30 ; Prime line 2
G92 E0 ; Reset extruder
G1 Z2.0 F3000 ; Lift nozzle
G1 X5 Y20 Z0.3 F5000.0 ; Move away from prime line
